# Tarefa 3 - CT-13 a CT-17: Validar regra de exatamente 4 dígitos numéricos

## Status Geral: ✅ Todos os 5 testes aprovados (via `npm test`)

### Contexto
A validação do PIN no backend foi alterada de aceitar de 4 a 8 dígitos (`/^\d{4,8}$/`) para aceitar **exatamente 4 dígitos** (`/^\d{4}$/`), garantindo que PINs como `'0123'` sejam tratados como string e não percam o zero à esquerda.

### Casos de Teste

| CT-# | Descrição | Entrada | Status | Resultado Específico |
|------|-----------|---------|--------|----------------------|
| **CT-13** | PIN válido de 4 dígitos | `'1234'` | ✅ Aprovado | PIN aceito como string, login permitido |
| **CT-14** | PIN válido começando com zero | `'0123'` | ✅ Aprovado | Zero preservado como string, sem conversão para número |
| **CT-15** | Rejeição de PIN com 3 dígitos | `'123'` | ✅ Aprovado | Lançado `DadoInvalido: PIN deve conter exatamente 4 dígitos numéricos.` |
| **CT-16** | Rejeição de PIN com 5 dígitos | `'12345'` | ✅ Aprovado | Lançado `DadoInvalido: PIN deve conter exatamente 4 dígitos numéricos.` |
| **CT-17** | Rejeição de PIN com caracteres não numéricos | `'12a4'` | ✅ Aprovado | Lançado `DadoInvalido: PIN deve conter exatamente 4 dígitos numéricos.` |

### Mudanças Realizadas

1. **`server/src/application/services/AuthService.js`** (linha 24):
   - Regex alterada de `/^\d{4,8}$/` para `/^\d{4}$/`
   - Mensagem de erro atualizada de `'PIN deve conter de 4 a 8 dígitos numéricos.'` para `'PIN deve conter exatamente 4 dígitos numéricos.'`

2. **Testes Automatizados** (adicionados em `server/tests/services.test.js`):
   - 5 novos testes unitários cobrindo todos os cenários acima
   - Todos os testes passam ao rodar `npm test`
